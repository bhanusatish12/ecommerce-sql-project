# ecommerce-sql-project
Designed an E-Commerce database using MySQL with tables for customers, products, orders, and payments. Built relational schema with keys and ER diagram. Wrote advanced SQL queries using joins, CTEs, and window functions to analyze sales trends, top products, and customer behavior, and optimized performance with indexing.
